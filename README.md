# Shop Ease Duo

Build a single-page e-commerce website called "ShopEase" with two sections on one page. (1) Storefront: hero banner, product grid with image, name, price, stock status, and an "Add to Cart" button, category filter, search bar, and a cart drawer with quantity controls and total. (2) Inventory Management Panel (a tab or toggle on the same page): a table of all products with add, edit, delete, update stock quantity, a low-stock warning (under 5 units), and a summary of total products, total stock value, and out-of-stock items. Use in-memory state with 8 sample products, so the storefront and the inventory panel stay in sync. Make it responsive, clean, and modern.
